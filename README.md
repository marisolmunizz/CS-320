How can I ensure that my code, program, or software is functional and secure?

I ensure that my code is functional by writing unit tests that verify both expected behavior and invalid inputs. Throughout this course, I used JUnit to test each class and service I created, making sure requirements such as field length limits, unique IDs, valid dates, and update operations all worked correctly. I also reran my tests after making changes to confirm that new code did not introduce defects. To improve security and reliability, I validated all user input, prevented invalid data from being stored, and threw exceptions when requirements were violated. This approach helped me build software that was both dependable and resistant to common errors.

How do I interpret user needs and incorporate them into a program?

I begin by carefully reviewing the software requirements and identifying both the functional requirements and any constraints. Before writing code, I determine what the program must accomplish and what rules must be enforced. During this course, I translated requirements into Java classes and JUnit tests that verified every requirement was met. By writing tests for both valid and invalid situations, I was able to confirm that the software behaved as users and stakeholders expected.

How do I approach designing software?

I approach software design by breaking a project into smaller, manageable components that each have a clear responsibility. I first identify the data the program needs, then design classes that represent that data and services that manage it. After implementing the required functionality, I create unit tests to verify each component independently before integrating everything together. This process makes the software easier to understand, maintain, and debug while improving overall quality. Throughout this course, I learned that designing with testing in mind leads to more reliable software and helps identify defects early in development.
